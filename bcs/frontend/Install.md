# Installation

```Bash
# React Router
npm install react-router-dom@7.9.0

# Axios
npm install axios@1.12.0

# Material UI
npm install @mui/material@9.4.0
npm install @emotion/react@11.14.0
npm install @emotion/styled@11.14.0

# Material Icons
npm install @mui/icons-material@9.4.0

# DataGrid
npm install @mui/x-data-grid@9.15.0

# DayJS (für Rechnungsdatum, Leistungsdatum, Fälligkei
npm install dayjs

# Testbibliotheken
npm install -D vitest
npm install -D jsdom
npm install -D @testing-library/react
npm install -D @testing-library/jest-dom

```
